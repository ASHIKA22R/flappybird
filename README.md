# Flappy Bird (HTML, CSS, JavaScript)

A small browser game built with vanilla HTML, CSS, and JavaScript using the Canvas API.

## Run the game
1. Extract `flappy_bird_game.zip`.
2. Open `index.html` in a modern browser.
3. Press **Start Game**, then use **Space**, **Arrow Up**, click, or tap to flap.
4. Avoid the pipes. Your best score is saved in your browser.

## Files
- `index.html` — game layout
- `style.css` — responsive styling
- `script.js` — gameplay, collision detection, scoring, and drawing

No installation or server is required.
